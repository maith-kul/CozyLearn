# 🐼 CozyLearn

CozyLearn is an AI-powered smart study companion that helps students learn faster and revise efficiently.

## ✨ Features

- 📄 Upload PDF, DOCX, TXT and Images
- 🤖 AI-generated Summaries
- ❓ Smart MCQs with Answers
- 🧠 Flashcards
- ⭐ Important Points
- 📌 Priority Topics
- 📅 Study Planner
- 📥 PDF Download
- 🔍 OCR Support for Images
- 📱 Responsive Design

## 🛠️ Technologies Used

- PHP
- HTML5
- CSS3
- JavaScript
- Gemini AI API
- Tesseract OCR
